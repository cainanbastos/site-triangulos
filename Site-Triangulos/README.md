# Triângulos — Guia de geometria

Site educativo em HTML, CSS e JavaScript puro, sem dependências. Abra `dist/index.html` no navegador.

## Conteúdo e requisitos
- HTML semântico: header, nav, main, section, article, figure, footer e listas.
- Classificações por lados, por ângulos e fórmulas de área e perímetro.
- Diagramas SVG com títulos acessíveis e exemplos numéricos.
- CSS Grid: uma coluna abaixo de 640 px, duas entre 640 e 1023 px, três a partir de 1024 px.
- Campo de pesquisa no rodapé, com filtro por texto e sem depender de rede.
- Navegação por teclado, indicação de foco, link para pular ao conteúdo e redução de movimento.

## Arquivos
- dist/index.html: estrutura e conteúdo.
- dist/styles.css: cores, espaçamento, Grid e media queries.
- dist/script.js: pesquisa com suporte a acentos.
- APRESENTACAO.md: roteiro para demonstração.

## Publicar no GitHub pelo navegador
1. Entre em sua conta e crie um repositório público chamado `site-triangulos`.
2. Extraia o ZIP. Envie os arquivos e a pasta dist em “Add file > Upload files”. Não envie o ZIP fechado.
3. Confirme em “Commit changes”.
4. Entregue o endereço do repositório que aparece na barra do navegador.

## GitHub Pages (opcional)
Para facilitar, envie também os três arquivos de `dist` diretamente na raiz do repositório. Em Settings > Pages, escolha Deploy from a branch, branch main, pasta /(root), e Save. Aguarde o endereço informado pelo GitHub.

## Integrantes
Preencha com os nomes de até três integrantes antes de entregar.
